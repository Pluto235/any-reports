Crab SED Roadmap (ML-energy × Nhit 2D binning)¶

Goal. Validate the ParticleNet-based per-event energy reconstruction by reproducing the Crab Nebula SED on two months of WCDA observation data (2022-01-01 to 2022-02-28), using a 2-D (Nhit, log10 E_pred) binning scheme on top of the standard WCDA forward-folding analysis.

Reference: 胡世聪博士论文 LHAASO-WCDA 伽马源分析与源表 (2023), Ch. 6 + Appendix on GRB 221009A.

1. Why 2-D binning instead of Nhit only¶

The traditional WCDA pipeline (Hu 2023, §6.2) bins events along a single axis — Nq05t30 — and forward-folds the assumed source spectrum through the detector response η(θ, E) to get an expected count per Nhit bin. The reason it does not bin in reconstructed energy is that per-event energy resolution from pool-only reconstruction is too poor to be useful.

With the ML regressor (runs/theta_recoxy_position_embed_midenergy_8666) we now have a per-event log10(E_pred / GeV) whose resolution is good enough to be a useful second axis. Adding it as a second binning dimension does two independent things:

  1. Inside a fixed Nhit bin, splitting on log E_pred separates events with different true energies that previously got averaged together. This sharpens the response matrix and gives the fit more leverage on the spectral shape.
  2. The Nhit axis is preserved so the analysis remains directly comparable to the published WCDA-1 catalog result (Hu 2023, Fig. 6-32) — the 1-D Nhit-only fit is recovered by marginalising the 2-D response over the log E_pred axis.

This is structurally the same idea as IACTs using both reconstructed energy and reconstructed gamma/hadron score as separate axes — the second axis is allowed to be noisy, the fit takes care of it through the response matrix.

The 2-D bin grid was already prototyped in apply/simulation_all_bin.py, producing apply/summary_selectedcuts/bin_counts.md:

  • Nhit bins (8): [30,60), [60,100), [100,200), [200,300), [300,500), [500,800), [800,1100), [1100,2000)
  • log10 E_pred bins (11): <2, [2,3), [3,3.25), [3.25,3.5), [3.5,3.75), [3.75,4.0), [4.0,4.25), [4.25,4.5), [4.5,4.75), [4.75,5.0), >=5
  • 60 of 88 inner cells are labelled acceptable (≥ ~1000 MC events after cuts) — these will be the only cells used in the fit. The rest are dropped to avoid empty / under-sampled bins driving the χ².

Nhit on the observation side is the nv branch in the apply-time output ROOT (same proxy as used in simulation_all_bin.py:get_nhit_value).

3. Forward-folding formalism, generalised to 2-D¶

Let b = (i_N, i_E) index a 2-D cell with i_N ∈ Nhit bins and i_E ∈ log E_pred bins. For a source with assumed differential spectrum I(E; Θ_S):

\[N_b^{\text{exp}}(\Theta_S) \;=\; \iint I(E;\Theta_S)\,\cos\theta\,\eta_b(\theta, E)\,S_0\,T_0\,f(\theta)\,d\theta\,dE\]

where

  • η_b(θ, E_true) = (events in cell b after all cuts) / (thrown events) is the 2-D detector response, computed once from MC under exactly the cuts used on the observation.
  • S_0 is the simulation throwing area.
  • f(θ) is the source-specific normalized zenith distribution over the observing window.
  • T_0 is live time.

This is identical in form to Hu 2023 eq. (6-6); the only change is that η_b is now indexed by a (Nhit, log E_pred) cell instead of a Nhit segment.

The 1-D Nhit forward folding is recovered by η_{i_N}(θ, E) = Σ_{i_E} η_{(i_N,i_E)}(θ, E).

Stage A — Detector response on the 2-D grid¶

  • Run the same checkpoint that produced the eval ROOTs across the full MC sample (not just test split) and dump per-event (E_true, θ_true, nv, log10 E_pred, passed_cuts). apply/simulation_all_bin.py already does the heavy lifting; extend it to also retain E_true and θ_true.
  • Apply the same event-level cuts as the observation reduction (Stage C). Critically: pincness < 1.1, fitstat == 0, θ < 50°, plus the dcedge / core_box cuts present in the model's config.json.
  • For each cell b = (i_N, i_E) and each (log10 E_true, θ_true) bin (Δlog10 E = 0.1, Δθ = 1° — same as Hu 2023):
    • η_b(θ_k, E_j) = N_pass(b, E_j, θ_k) / N_thrown(E_j, θ_k)
    • Multiply by S_0 (simulation thrown area) to get effective area when needed.
  • Output: response_2d.npz with shape (N_cells, N_E_true, N_theta) for both η and A_eff. Only cells flagged acceptable in bin_counts.md are kept; the rest are dropped from b.

Stage B — PSF per cell on the Crab dec band¶

  • Crab dec = 22.01°, LHAASO lat = 29.45° → θ_min ≈ 7.4°. Build PSF only at this dec band initially.
  • For each cell b, weight MC events by the Crab zenith distribution f_Crab(θ) over the analysis window, fit a single Gaussian to the radial offset (reco − true) → σ_b. Two-Gaussian fits are optional; single Gaussian is enough for a first pass.
  • Use the optimal aperture from Hu 2023 (Δθ_opt ≈ 1.58 σ_b) per cell. Containment fractions per cell are saved alongside σ_b.

Stage C — Observation reduction¶

For each Esg*.root + friend .time.root:

  1. Keep events with match_status == 0, pincness < 1.1, fitstat == 0, theta < 50°.
  2. Compute the cell b = (i_N, i_E) from nv and ml_logE_pred. Drop events whose cell is not in the acceptable list.
  3. Carry forward (ra_mean_deg, dec_mean_deg, mjd, theta, b) per event.

Output: a single per-month parquet obs_events.parquet (column-store; ~100M events × ~6 columns is fine on disk and fast to scan). One file per month keeps it manageable.

Compute the live time from MJD coverage minus the duty-cycle gaps. The handoff confirms 1258 input files, 127.69M total events recovered; this is the universe for the live-time count.

Stage D — Background estimation¶

Use direct integration (Hu 2023, §6.1.5 — the method chosen for the WCDA-1 catalog, α ≈ 0.01, robust against acceptance time-variation). Concretely:

  • Build the time-integrated all-sky acceptance map G(x, y) from the same cleaned event sample, masking a 2° radius around Crab (and around Mrk 421 / Mrk 501 / Geminga / Cygnus region to be safe — they're well outside the Crab analysis ROI but cheap to mask).
  • For each cell b, build G_b(x, y) independently — the acceptance shape is cell-dependent.
  • Background prediction in any (RA, Dec) bin: N_off · α = G_b(x,y) · R_b(t) integrated over the live-time window, where R_b(t) is the cell-b all-sky event rate as a function of time.

If the catalog program from Hu Shicong is accessible, reuse it — re-implementing the full direct-integration with mask handling correctly is the most error-prone part of the analysis. If not available, fall back to the simpler 等赤纬法 (equal-declination band background) for the initial Crab cross-check; α is larger (~0.01 vs 0.012 at dec=39°) but the method is much simpler and Crab is bright enough that it does not matter for SED shape, only for absolute normalisation systematics.

Stage E — Signal extraction¶

For each cell b:

  • Aperture radius r_b = 1.58 σ_b from Stage B.
  • N_on,b = events in the Crab on-region (aperture around RA=83.63°, Dec=22.01° in cell b).
  • N_off,b · α_b = direct-integration background prediction summed over the same aperture, same cell.
  • excess_b = N_on,b − α_b N_off,b, σ_b^stat = √(N_on,b + α_b² N_off,b).
  • Li-Ma significance per cell (Hu 2023 eq. 6-26) for diagnostics.

Diagnostics expected at this stage:

  • A 2-D significance map (Nhit × log E_pred) — should show a positive diagonal correlation (high Nhit ↔ high log E_pred), and the off-diagonal "wings" tell you how much the ML axis is adding over Nhit.
  • Total Crab significance summed over all acceptable cells; sanity target ~90σ.

Stage F — Forward-folding fit¶

Minimise

\[\chi^2(\Theta_S) \;=\; \sum_{b \in \text{acceptable}} \frac{\big(\text{excess}_b - N_b^{\text{exp}}(\Theta_S)\big)^2}{(\sigma_b^{\text{stat}})^2}\]

with iminuit. Spectral models, tried in order:

  1. Power law I(E) = N_0 (E/E_0)^{-Γ}, E_0 = 3 TeV (matches WCDA-1 catalog pivot).
  2. Log-parabola I(E) = N_0 (E/E_0)^{-α − β log(E/E_0)} — Crab is known to curve slightly.
  3. Power law with exponential cutoff (only if (2) residuals demand it).

The simulated Crab response in Hu 2023 was generated with index −2.62 across 10 GeV–1 PeV. We can use the same response for forward folding because the response is the migration matrix, not the assumed spectrum — but it is good practice to iterate once with the best-fit spectrum to re-weight A_eff.

Stage G — SED points¶

Following Hu 2023's standard practice:

  • Fix the best-fit global Γ (or α, β) from Stage F.
  • For each Nhit bin (or each i_E bin — present both views) re-fit only the normalisation N_0,bin with all other parameters frozen.
  • Convert to differential E² dN/dE at the bin's median true energy (computed by weighting the response by the best-fit spectrum).
  • Compare directly against:
    • WCDA-1 catalog Crab (Hu 2023 Fig. 6-32): N_0 = 2.114 × 10⁻¹³ cm⁻² s⁻¹ TeV⁻¹ at 3 TeV, Γ = 2.69 ± 0.01.
    • HAWC and HESS Crab SEDs as external sanity references.

The 1-D-Nhit-only SED is produced as a by-product by marginalising the response over i_E and refitting — this is the apples-to-apples comparison to the catalog.

5. Systematic checks¶

Run all four as separate sanity outputs, not just as paragraphs in a summary:

  1. 1-D vs 2-D consistency. Marginalise the 2-D response to recover the 1-D Nhit-only fit. The two SEDs must agree within statistical errors; large disagreement means the 2-D η matrix is mis-normalised somewhere.
  2. Response self-consistency. Forward-fold the input MC spectrum (Γ = −2.62) through the response and confirm the predicted per-cell counts match the MC-passed counts in bin_counts.md to ≲ 1%.
  3. Cell-drop sensitivity. Re-fit with the threshold for "acceptable" raised by 2× (drop more low-stats cells) and lowered by 2× (include more). The Crab Γ and N_0 should drift by less than the statistical error.
  4. Cut sensitivity. Tighten pincness < 0.9 and re-run the full pipeline (response and observation must use the same tighter cut). The fitted SED should be statistically consistent.
  5. Background-method sensitivity. If both direct-integration and equal-declination-band backgrounds are implemented, fit with each and quote the spread as a background-method systematic.

The end-of-pipeline systematic-error budget mirrors Hu 2023 §6.8.1: the ML-vs-WCDA-1 ratio band, expected within ±10% from 1 to 20 TeV if the ML reconstruction is unbiased.

7. Open decisions¶

  1. Background method for v1: direct integration (matches WCDA-1) vs equal-declination (simpler, ~10× faster to implement). Recommendation: start with equal-declination to get end-to-end through Stage G, then swap in direct integration.
  2. Whether to reuse Hu Shicong's catalog fitter as the Stage F backend, or write a minimal iminuit fitter from scratch. Recommendation: write from scratch — 2-D response indexing is custom anyway, and the χ² is ~50 lines.
  3. PSF parameterisation — single Gaussian (fast, good enough for Crab) vs double Gaussian (closer to the catalog's choice). Recommendation: single for v1, revisit only if Stage E containment looks off.
  4. Cell selection — start with the 60 acceptable cells from bin_counts.md and iterate.

These do not block starting Stage A.
