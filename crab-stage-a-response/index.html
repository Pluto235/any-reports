本次 Stage A 输出的是 conditional eventout response，即在已进入 MC eventout 且通过分析 cuts 的条件下，事件落入某个观测 cell 的概率矩阵。绝对有效面积 A_eff 需要真实 thrown normalization 与投掷面积 S0，当前尚未写死，因此本报告不把 conditional response 解释为绝对有效面积。

1. 计算定义

观测 cell 定义为 b = (Nhit bin, log10 E_pred bin)。v1 baseline 只使用 apply/config/cell_selection_v1.csv 中的 18 个 physical-band cells。

eta_conditional[b, E_j, theta_k]
  = sum(mc_weight for events in cell b, true bin E_j, theta_k)
    / sum(mc_weight for all cut-passed eventout events in true bin E_j, theta_k)

同时保存了裸计数版本 eta_conditional_count，用于审计和 sanity check；baseline 拟合使用 mc_weight 加权版本。

5. 产物与限制

生成的 Stage A 文件：

  • response_2d.npz: 响应矩阵、分子/分母计数、truth-grid edges 和 cell labels。
  • response_2d_metadata.json: cuts、模型、输入路径、运行统计和响应类型。
  • cell_response_summary.csv: 18 个 v1 cell 的 numerator 汇总。
  • denominator_occupancy.csv: 每个 truth bin 的 denominator occupancy。
  • response_2d_summary.md: 简要文字摘要。

当前限制：A_eff 数组目前全部为 NaN（验证结果：True）。这是有意保留的状态，避免在 thrown normalization 与 S0 未确认前，把 conditional response 误当作绝对有效面积。Stage F 若要做绝对通量拟合，需要先补齐这部分归一化。
